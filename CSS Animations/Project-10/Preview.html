✨ Project11 - Neon Glow Pulse ✨

NEON

📌 Properties Used:

• text-shadow: Creates glowing text effect with multiple layers (0 0 10px color)

• box-shadow: Creates outer glow (0 0 30px) and inset inner glow

• border-color: Changes color during animation

• transform: scale(): Makes elements grow and shrink

• opacity: Controls transparency during pulse

• animation-timing-function: ease-in-out: Smooth start and end

• letter-spacing: Creates spaced out text effect

• transition: Smooth hover effects
